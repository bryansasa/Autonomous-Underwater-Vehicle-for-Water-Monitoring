Referensi & target

Set Surface: menetapkan nol tekanan di permukaan saat IDLE. Bukan perintah naik.

Referensi yaw: heading asli tetap disimpan. Jika arah menghadap 37° dijadikan nol, yaw misi 0° berarti heading asli 37°; target misi 90° berarti heading asli 127°. Mematikan referensi mengembalikan tampilan dan target ke heading asli. Ini bukan kalibrasi magnetometer atau posisi XY.

Referensi tidak dapat diubah ketika misi aktif. Target dikonversi ke heading asli saat membuat snapshot misi.

Default: heading asli magnetometer

Set Surface adalah kalibrasi nol saat IDLE. Interface target langsung masih perlu dibangun.
