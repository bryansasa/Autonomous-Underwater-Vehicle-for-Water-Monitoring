PANDUAN PENYELESAIAN GAZEBO BLACK SCREEN

Simulasi Robot ROV Tyrant-AQ & Medan Air Saguling (ROS 2 / Ubuntu Linux)

OS: Ubuntu 22.04 / 24.04 LTS Simulasi: Gazebo Sim (gz-sim) / Gazebo Classic Target: ROS 2 Humble / Jazzy
Ringkasan Masalah: Layar hitam (viewport kosong/gelap) di Gazebo terjadi ketika proses simulasi berjalan di background, namun engine rendering grafis (OGRE 2 / OpenGL) gagal membuat konteks 3D di layar monitor Ubuntu Anda.

DIAGNOSIS Langkah Cepat: Cek Pesan Error

Sebelum mencoba berbagai cara, buka terminal Ubuntu dan jalankan Gazebo dengan mode verbose level 4 untuk melihat log error asli:

# Jika menggunakan Gazebo Sim modern (perintah: gz sim)
gz sim -v 4

# Atau jika menggunakan Gazebo Classic (perintah: gazebo)
gazebo --verbose

Perhatikan baris teks berwarna merah atau tulisan bertanda [Err]:

  • Jika muncul: [GUI] [Err] ... Ogre2RenderEngine → Masalah Render Engine OGRE2 (Paling sering!).
  • Jika muncul: Failed to create OpenGL context / libGL error → Masalah Driver GPU / OpenGL.
  • Jika muncul: Waiting for master... atau stuck tanpa error → Masalah Download Model OSRF Timeout.

SOLUSI 1 Ganti Engine Rendering ke OGRE 1 (Rekomendasi Utama)

Gazebo Sim modern (Ignition/GZ Sim) menggunakan OGRE2 secara default. OGRE2 sangat rentan mengalami black screen jika dijalankan di GPU terintegrasi (Intel Iris/UHD, AMD Radeon bawaan processor), laptop dual GPU, atau mesin virtual (VM/WSL).

Langkah Eksekusi:

# Jalankan Gazebo dengan flag engine OGRE 1
gz sim --render-engine ogre

Solusi Permanen untuk ROS 2 Launch Proyek Anda:
Di proyek Anda, file launch simulasi_rov_gazebo.launch.py memanggil gz sim. Agar launch file otomatis memakai OGRE 1 tanpa perlu mengedit skrip Python, tambahkan environment variable ke ~/.bashrc:

# Tambahkan variabel ke konfigurasi bash Ubuntu
echo "export GZ_RENDERING_ENGINE=ogre" >> ~/.bashrc
source ~/.bashrc
Hasil: Setelah perintah di atas dijalankan, setiap kali Anda menjalankan ros2 launch tyrant_gazebo_sim simulasi_rov_gazebo.launch.py, Gazebo akan selalu memakai OGRE 1 yang stabil dan layar tidak akan hitam lagi!

SOLUSI 2 Mengatasi Dual GPU (Laptop NVIDIA + Intel)

Banyak laptop mahasiswa menggunakan konfigurasi dual GPU (Intel terintegrasi + NVIDIA RTX/GTX). Secara default, Ubuntu sering kali me-render Gazebo via Intel yang driver OpenGL-nya tidak sinkron.

1. Cek apakah Driver NVIDIA aktif:

nvidia-smi

Jika muncul tabel informasi GPU, driver NVIDIA sudah terpasang. Jika command not found, instal driver dengan: sudo ubuntu-drivers autoinstall lalu sudo reboot.

2. Paksa Gazebo berjalan di GPU NVIDIA (PRIME Offload):

__NV_PRIME_RENDER_OFFLOAD=1 __GLX_VENDOR_LIBRARY_NAME=nvidia gz sim

SOLUSI 3 Jika Menggunakan WSL2 (Windows Subsystem for Linux)

Jika Ubuntu Anda diakses melalui WSL2 di Windows 11/10:

  1. Update komponen WSLg di Windows:
    Buka PowerShell di Windows (Run as Administrator) lalu jalankan:
    wsl --update
  2. Gunakan Software Rendering (Fallback jika OpenGL crash):
    Di terminal Ubuntu WSL2:
    export LIBGL_ALWAYS_SOFTWARE=1
    gz sim
    (Catatan: Mode ini merender via CPU. Gerakan sedikit lebih berat namun 100% mem-bypass crash hardware grafis).
  3. Pilih GPU NVIDIA untuk Direct3D 12 di WSL:
    export MESA_D3D12_DEFAULT_ADAPTER_NAME=NVIDIA

SOLUSI 4 Reset Cache GUI Gazebo yang Rusak (Corrupt)

Terkadang Gazebo pernah crash atau ditutup paksa (Ctrl+C), sehingga layout window GUI dan plugin scene broadcaster tersimpan dalam kondisi corrupt di direktori home pengguna.

# 1. Hapus cache konfigurasi Gazebo Sim modern:
rm -rf ~/.gz/sim/

# 2. Hapus cache Ignition (jika pakai versi ignition):
rm -rf ~/.ignition/gazebo/

# 3. Hapus cache Gazebo Classic (jika pakai gazebo 11):
rm -rf ~/.gazebo/gui.ini

SOLUSI 5 Khusus Jika Menjalankan Gazebo Classic (gazebo)

Jika kemarin yang dijalankan adalah perintah gazebo (Gazebo versi 9 / 11), layar hitam pekat sering disebabkan Gazebo sedang diam (stuck) mendownload model-model standar (seperti sun dan ground_plane) dari server OSRF yang sangat lambat/diblokir ISP.

# Download dan pasang semua model standar secara manual secara lokal:
mkdir -p ~/.gazebo/models
git clone https://github.com/osrf/gazebo_models.git ~/.gazebo/models

CHECKLIST Menjalankan Simulasi Proyek Tyrant-AQ di Ubuntu

Berikut alur lengkap yang sudah disesuaikan dengan workspace Anda (ros2_ws):

# 1. Pindah ke direktori workspace ROS 2 Anda
cd ~/ros2_ws

# 2. Source environment ROS 2
source /opt/ros/$ROS_DISTRO/setup.bash

# 3. Build paket simulasi
colcon build --packages-select tyrant_gazebo_sim
source install/setup.bash

# 4. Set render engine agar tidak black screen
export GZ_RENDERING_ENGINE=ogre

# 5. Jalankan Simulasi Penuh (Gazebo + ROV + Waduk Saguling + EA-DSRA)
ros2 launch tyrant_gazebo_sim simulasi_rov_gazebo.launch.py
